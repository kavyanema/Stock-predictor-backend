FastAPI backend that predicts short-term stock prices using Ridge Regression and real data from Yahoo Finance.

- ML-based prediction (Ridge Regression)
- Supports global markets (US, India, UK, etc.)
- Auto currency + exchange detection
- Outputs price, % change, trend
- Includes MAE, RMSE, MAPE
- Predictions capped to ±5% realistic movement
